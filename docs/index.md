# FRC 829 Programming

The programming side of robotics for **FRC Team 829**. This site holds the notes,
the setup instructions, and the reference material. It is not the robot code
itself &mdash; that lives in the team's repositories.

The plan for the fall is straightforward:

1. **Get Java under your fingers.** You cannot write robot code you cannot debug,
   and you cannot debug code in a language you are still guessing at.
2. **Get a working toolchain.** WPILib, VS Code, gradle, and a deploy that
   actually lands on the robot.
3. **Learn DigiLib**, the team's own framework, and start contributing to it.

!!! info "We are on WPILib 2026.2.1"
    2027 is still in alpha. Everything here targets **2026.2.1** and the roboRIO
    so that what you learn runs on hardware we already have. Sometime in
    **December**, once 2027 settles into its final shape, we move over &mdash; and
    there is a real amount that changes. See [Getting started](getting-started/index.md).
